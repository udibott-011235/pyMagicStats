# Teoría compartida

Este espacio contiene los contratos científicos vigentes del proyecto. Una nota
teórica debe declarar estimando, diseño, supuestos, alcance, fuentes/evidencia y
qué observación podría refutarla o forzar su revisión.

La teoría no se organiza por función de Python, sino por pregunta inferencial.
El punto de partida vigente es
[`inference-principles.md`](inference-principles.md).
