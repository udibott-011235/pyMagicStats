# Perspectiva: arquitectura e implementación

**Asignación actual:** Codex/GPT.

Este rol convierte teoría y decisiones aceptadas en contratos de API, módulos,
tests y documentación coherentes.

Toda nota debe incluir:

- IDs de teoría/decisión/evidencia consumidos;
- baseline exacto y mapa de componentes afectados;
- invariantes y compatibilidad;
- tests de contrato, regresión y bordes;
- riesgos que requieren QA estadístico;
- criterio de handoff a Antigravity o Cortex.

Este espacio no puede declarar una calibración aceptada sólo porque la
implementación o el test suite pasen.
