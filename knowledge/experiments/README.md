# Experimentos

Un experimento es un paquete reproducible: pregunta, hipótesis, baseline,
escenarios, estimando, métricas, semillas, comando, entorno, outputs y límites.
Las corridas exploratorias pueden registrarse como `proposed`; sólo una corrida
reproducible y revisada puede respaldar `validated_with_limits`.

`EXP-001` corresponde al runner
`experiments/robustness_calibration.py` y su evidencia `EV-001`.

Use [`EXPERIMENT_RECORD_TEMPLATE.md`](EXPERIMENT_RECORD_TEMPLATE.md).
