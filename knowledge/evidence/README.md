# Evidencia

La evidencia conecta una afirmación con artefactos observables. Cada registro
debe indicar población/escenarios, estimando, métrica, commit, entorno,
reproducibilidad y limitaciones. Una tabla de resultados sin runner o una
conclusión sin artefacto no es evidencia suficiente.

El inventario inicial está en [`current-evidence.md`](current-evidence.md).
