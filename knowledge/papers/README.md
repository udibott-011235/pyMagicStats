# Papers y fuentes teóricas

Este espacio guarda fichas críticas, no una colección indiscriminada de PDFs.
Cada paper debe vincularse a uno o más IDs del registro y distinguir entre lo
que la fuente afirma, la interpretación del agente y la decisión del proyecto.

Reglas:

- preferir DOI, URL del editor o repositorio legal;
- registrar versión, año y páginas/secciones relevantes;
- anotar población, supuestos y límites de transferencia a pyMagicStats;
- no subir PDFs con copyright sin licencia compatible;
- marcar retractaciones, erratas o desacuerdos.

Use [`PAPER_NOTE_TEMPLATE.md`](PAPER_NOTE_TEMPLATE.md).
